# PhotoCraft Guide feedback

Public corrections and feedback for [artcraftphotocraft.com](https://artcraftphotocraft.com/), an independent download and tutorial guide maintained by [Bellacai17](https://github.com/Bellacai17).

[Report a guide correction](https://github.com/Bellacai17/artcraftphotocraft-feedback/issues/new/choose) for inaccurate instructions, broken links or unclear explanations. Include the page URL, PhotoCraft version, operating system, what should change and a public source or reproducible steps.

This repository contains feedback documentation only. The website's source repository remains private. Reports are public: do not attach private photos, client documents, credentials or personal information. We review feedback during guide maintenance; no response time is promised.

For a bug in PhotoCraft itself, use the [official software issue tracker](https://github.com/storytold/photocraft/issues). The official project does not maintain this guide.

## 中文反馈

这里是 [artcraftphotocraft.com 中文指南](https://artcraftphotocraft.com/zh/)的公开纠错入口。下载说明不准确、步骤与版本不符、链接失效或解释不清楚，都可以提交 Issue。请提供页面地址、软件与系统版本、需要更正的内容，以及公开来源或复现步骤。

所有报告会公开显示，请勿上传私人照片、客户文件、账号凭证或个人资料。本站由 Bellacai17 独立维护；PhotoCraft 软件本身的问题请提交到官方项目。
